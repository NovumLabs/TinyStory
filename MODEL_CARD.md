# Model Card: TinyStory (4.2M)

## Summary

A decoder-only transformer trained from scratch to continue short children's
stories in English. It was built for learning purposes and is not intended for
production use.

## Model details

| Property | Value |
|----------|-------|
| Architecture | GPT-style decoder-only transformer, pre-LayerNorm, GELU MLP |
| Parameters | 4.2M (input and output embeddings tied) |
| Layers / heads / width | 4 / 4 / 256 |
| Context length | 128 tokens |
| Vocabulary | 4,096 byte-level BPE tokens (+ `<|endoftext|>`) |
| Dropout | 0.1 |
| Framework | PyTorch |
| License (code) | MIT |

## Training data

- 49,500 training stories from TinyStories (500 further stories held out for validation)
- Three public-domain Project Gutenberg collections (Grimm, Andersen, Aesop for Children), repeated 3x in training, with the last 5% of each held out
- 12.2M training tokens and 145K validation tokens

See [DATASET.md](DATASET.md) for sources and the preparation pipeline.

## Training procedure

| Setting | Value |
|---------|-------|
| Optimiser | AdamW, weight decay 0.1 |
| Learning rate | 6e-4, 100 warm-up steps, cosine decay to 6e-5 |
| Batch | 32 sequences x 128 tokens |
| Iterations | 8,000 (32.8M tokens processed, about 2.7 passes over the training set) |
| Gradient clipping | 1.0 |
| Hardware | single consumer CPU, no GPU (~4.3 hours) |

## Evaluation

Best validation loss: **2.629** nats per token (train loss about 2.55 at the
end of training), measured on the project's own held-out split. The small
train/validation gap indicates the model is limited by capacity rather than by
overfitting. There is no standard benchmark for this model; quality was judged
by reading samples.

## Intended use

- Learning how language models are built and trained
- Experiments with tokenisation, sampling and small-scale training
- A baseline for scaling experiments

## Limitations

- Output is repetitive and characters are mixed up over longer passages.
- Occasionally produces glued words (for example a missing space) at higher
  repetition penalties.
- Knowledge and vocabulary are limited to simple children's stories.
- Continues text; it does not follow instructions.
- English only.

## Bias, safety and ethics

The training stories are synthetic (generated by large language models) and
inherit their stylistic and cultural biases, such as common Western names and
settings. The public-domain fairy tales contain outdated social attitudes and
occasionally violent plots. The model has no safety tuning; review outputs
before showing them to children or publishing them.

## How to use

```bash
python generate.py "Once upon a time, a girl found a magic" \
    --ckpt ckpt.pt --tokenizer data/tokenizer.json --temperature 0.5
```

Recommended sampling: temperature 0.5 - 0.6, top-k 40, repetition penalty 1.0 - 1.05.
